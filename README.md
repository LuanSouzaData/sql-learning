# SQL Learning

A structured SQL learning repository, starting from the fundamentals and progressing to advanced SQL concepts.

## Goals

- Learn SQL fundamentals
- Practice database creation and data manipulation
- Understand relational database concepts
- Practice data querying and analysis
- Work with CSV data
- Learn intermediate and advanced SQL
- Develop professional Git and version control habits

## Database

PostgreSQL

## Topics

- SQL Fundamentals
- Data Definition Language (DDL)
- Data Manipulation Language (DML)
- Filtering and Sorting
- Aggregate Functions
- GROUP BY and HAVING
- Constraints
- JOINs
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Views
- Indexes
- Transactions
- Query Optimization
- CSV Data Import
